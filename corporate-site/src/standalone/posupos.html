    Features

    ポスポスでできること

    毎日のお会計と、その日の売上の確認。お店でいちばんよく使うところを、かんたんにしました。

    お会計

    注文を入れていけば、合計は自動で計算。ボタンひとつでお会計ができます。

    売上の管理

    お会計の記録がそのまま売上にまとまります。閉店後に手で集計する手間を減らせます。

    お店に合わせて

    昼の飲食店、居酒屋、夜のお店。営業のしかたに合わせた使い方を、導入のときにご相談できます。

    Functions

    機能一覧

    伝票や付け回しから、お客さま・ボトル・売掛の管理、スタッフのシフトや給料、確定申告まで。お店の毎日に必要なことを、ポスポスひとつにまとめました。

    お店の営業7

    • ホーム今日のお店の様子を、ひと目で
    • 店内席の状況を確認
    • 伝票注文とお会計を伝票で管理
    • 付け回しどの席に誰がついているかを管理
    • カレンダー来店予定などをカレンダーで共有
    • イベントお店のイベントを管理
    • オークションオークションの記録

    お会計・お金4

    • お金お店のお金の出入りを管理
    • 売掛売掛（ツケ）を記録して、回収までしっかり
    • 経費お店の経費を記録
    • 確定申告売上と経費の記録から、確定申告まで

    商品4

    • 出数・在庫どの商品がどれだけ出たか、在庫はいくつか
    • ボトルボトルキープを管理
    • ランキング売上のランキングを確認
    • 項目マスタ商品や料金の項目を登録

    お客さま2

    • 顧客お客さまの情報や来店の記録をまとめて管理
    • タグタグを付けて分けて管理

    スタッフ8

    • 従業員スタッフを登録
    • シフトシフトを作って共有
    • 勤怠出勤・退勤の記録を管理
    • 打刻端末ICカードをかざすだけで出退勤を打刻
    • 送り送りを管理
    • 給料給料を計算
    • 給与プランスタッフごとの給与の決め方を設定
    • 前借り前借りを記録して、給料の計算に

    連絡・設定・サポート3

    • チャットお店の中の連絡を、ポスポスの中で
    • アカウント使う人ごとのアカウントを管理
    • 24時間サポート困ったときは、夜中でも相談できます

    Flow

    導入の流れ

    1. お問い合わせ

      フォームから、お店の種類とご連絡先をお送りください。

    2. ヒアリング

      営業時間やお会計のしかたなど、お店のことを伺います。

    3. ご提案

      お店に合った使い方と、料金をご案内します。

    4. 利用開始

      設定が済んだら、お店で使いはじめられます。

    料金について
    料金は、お問い合わせいただいた方に個別にご案内しています。お気軽にご相談ください。
