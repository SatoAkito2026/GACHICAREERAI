# 利用規約に追加する条文（人材プロフィール・チケット・面談） — 下書き

## 第○条（人材プロフィールの公開）
1. 利用者は、自らの選択により、模擬面接の評価をもとにした人物まとめその他のプロフィール（以下「公開プロフィール」）を、本サービスに登録した企業（以下「企業利用者」）が閲覧できる状態にすることができます。
2. 公開プロフィールは、利用者が同意したときに限り公開され、利用者はいつでも非公開にできます。非公開にした後も、それ以前にチケットを購入した企業利用者は、購入時点までの内容を引き続き閲覧できる場合があります。
3. 利用者は、公開プロフィールのうち氏名を伏せて表示される項目（ひとこと・自己PR等）に、本人が特定される情報を記載しないものとします。
4. 当社は、公開プロフィールの内容について、AIによる評価を含め、その正確性・完全性を保証しません。

## 第○条（チケット）
1. 企業利用者は、当社所定の料金を支払ってチケットを購入することで、特定の利用者の公開プロフィールの詳細（氏名・面接ごとの評価・会話・録画（利用者が許可した場合））の閲覧と、面談の申し込みができます。
2. チケットの料金は、閲覧および連絡の権利に対する対価であり、採用の成否にかかわらず変わりません。当社は採用の成立に応じた報酬を受け取りません。
3. 購入したチケットは、法令に定める場合を除き、キャンセル・返金できません。
4. 企業利用者は、チケットにより得た情報を、当該利用者の採用の検討および連絡の目的にのみ使用し、第三者に提供してはなりません。

## 第○条（面談の申し込み・メッセージ）
1. 企業利用者は、チケットを購入した利用者に対して面談を申し込むことができます。利用者は、承諾または辞退を自由に選べます。
2. 申し込みが承諾された後は、企業利用者と利用者が本サービスのメッセージ機能で直接やり取りします。当社は、両者の間の日程調整・条件交渉・採否の連絡の取り次ぎ等を行わず、両者の間の契約（雇用契約を含む）の当事者になりません。
3. 企業利用者は、労働関係法令その他の法令を守り、求職者に対し、労働条件を正確に明示するものとします。
4. 次の行為を禁止します：虚偽の求人・労働条件の提示、面談を口実にした勧誘・営業、差別的な取り扱い、つきまとい・ハラスメント、本サービス外への誘導を目的とした連絡の乱用、その他当社が不適切と判断する行為。

## 第○条（当社の役割）
当社は、募集情報等提供事業者として、公開プロフィールを企業利用者が検索・閲覧できる場を提供するものであり、特定の利用者を特定の企業利用者に推薦・あっせんするものではありません。
