## このサービスの位置づけ（設計の考え方）

職業紹介（有料職業紹介の許可が必要）にならないよう、**求人メディア型（募集情報等提供）** として設計しています。

- 企業は、公開されたプロフィールを **自分で検索して選ぶ**。運営が特定の企業に特定の人を推薦・紹介することはしない
- 企業とユーザーは **直接** やり取りする。運営は日程調整・条件交渉などの仲介をしない
- 料金は **閲覧・連絡の権利（チケット）** に対してだけ。採用が決まっても成功報酬はとらない
- プロフィールは **初期状態で非公開**。本人の同意があるときだけ公開し、いつでも非公開にできる
- 企業からの面談の申し込みは、本人が **承諾・辞退を自分で選ぶ**

ユーザーの個人情報（プロフィール）を企業に提供するため、**特定募集情報等提供事業** の届出が必要になる見込みです（2022年10月の職業安定法改正）。届出の要否・方法は労働局に確認してください。
