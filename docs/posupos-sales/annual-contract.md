# ポスポス 年間契約の特典（営業用・社内メモ）

ホームページと営業資料には載せない。お問い合わせのあと、お見積もりのときに口頭・メールで案内する。
料金を見せないので、「◯か月分おトク」のような値引きではなく、お金以外の目に見える特典にする。

| 年数 | 特典 |
|---|---|
| 1年 | 登録費無料（商品・写真・スタッフの登録を、こちらでまるごと行う） |
| 2年 | 1年の特典 ＋ 契約の期間中は料金を変えない約束 ＋ お店に行って使い方の説明（1回） |
| 3年 | 2年の特典 ＋ 個別の作り込みを1つ無料（お店独自の給料の計算・帳票など）＋ 困ったときの優先対応 |

## 決まり

- 前払い（Stripe。領収書が出る）。自動では更新しない。終わる1か月前にお知らせする
- 途中でやめても、残りの期間のお金は返さない
- グループ店は、1店舗の金額 × 店舗の数
- 年間契約の間にお店を足すときは、お問い合わせで対応する

## お見積もりのときに送る文（例）

```
年間契約でお申し込みいただくと、次の特典がつきます。

・1年契約：登録費が無料（商品・写真・スタッフの登録を、こちらでまるごと行います）
・2年契約：1年の特典に加えて、契約の期間中は料金を変えません。お店に伺って使い方のご説明も1回いたします
・3年契約：2年の特典に加えて、お店独自の給料の計算や帳票などの作り込みを1つ無料でお作りします。お困りのときは優先して対応します

お支払いは前払いで、自動では更新しません（終わる1か月前にお知らせします）。
```

## 注意

- ポスポスのアプリの中の「年間契約」の画面に、前の特典（1年で1か月分・2年で3か月分・3年で5か月分おトク）が出ている場合は、アプリ側も合わせて直す（このリポジトリの外）
- 「料金を変えない約束」「作り込み1つ無料」は契約書・申込書にも書いておく
