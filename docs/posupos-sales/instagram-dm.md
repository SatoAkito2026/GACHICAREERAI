# Instagram 営業DM（ポスポス）

そのままコピーして使える文。【 】のところだけ、お店ごとに入れかえる。

## 送るときの決まり

- 1日10〜20件まで（できたばかりのアカウントは、一度にたくさん送ると止められる）
- 送る前に、お店の投稿に「いいね」してから送る
- 1通目にURLは入れない（迷惑メッセージに入りやすい）。返事が来てから送る
- 「営業お断り」と書いてあるお店には送らない
- 断られたら「承知しました、失礼いたしました」とだけ返して、もう送らない
- ホストクラブには売掛の話を入れない
- 3通目（追いかけ）は1回だけ
