# Instagram 投稿の予定とキャプション（ポスポス）

動画は https://akitogroup.jp/pospos-videos から保存して、リールで投稿する。
投稿する時間のめやす：16〜17時（夜のお店のオーナーが、開店前にスマホを見る時間）。
投稿したら、動画の一覧のページで「投稿済み」にしておく。

| 日にち | 動画 | ねらい |
|---|---|---|
| 1日目 11/8（日） | 広告：夜のこと、全部ポスポス（ad-night-40） | まず全体を見せる（もう投稿していたら飛ばす） |
| 2日目 11/9（月） | キャストはスマホで給料を確認（night-05-cast） | いちばん「あるある」の悩み |
| 3日目 11/10（火） | 付け回しは4つ選んで押すだけ（night-01-tsukemawashi） | 毎日の作業がラクになる |
| 4日目 11/11（水） | 締め作業は確認だけ（night-03-shukei） | 時間が減る |
| 5日目 11/12（木） | ランキングも自動で出る（night-04-ranking） | キャストのやる気 |
| 6日目 11/13（金） | セットの終わりを見のがさない（night-02-encho） | 売上の取りこぼしを防ぐ |

6本が終わったら、伸びた動画（再生・保存が多いもの）と同じ型で、新しい動画を足していく。
